# Session Flow (VS Code / Antigravity)

열린 작업 폴더의 Claude Code 세션들을 하네스(멤버 · 역할 · 메인 · 메시지 방향)로 설계하고, 실행 흐름과 파일 전/후 변경을 한 화면에서 확인하고 개입합니다.

- 왼쪽: 이 폴더의 다른 세션 (끌어와서 멤버로 추가)
- 가운데: 멤버와 메시지 방향 (설계 / 실행 흐름)
- 오른쪽: 역할, Claude Code 열기, 지시 보내기, 주고받은 메시지, 변경 파일 diff

같은 레포의 Claude Code 플러그인(`session-flow`)이 활동을 기록하고, 하네스대로 각 세션에 역할을 안내합니다.
